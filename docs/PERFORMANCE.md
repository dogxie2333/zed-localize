# 体积和常驻性能

Windows x64 本机验证。v0.3 多语言 EXE 约 **20.6 MiB**，首次解包约 **37 MiB**，包含 13 种离线词典、原生设置组件、官方 Gadget、静态前端及完整许可；不含 Python/Gradio/LiteLLM 运行时。相比此前 Python 版本约 147.1 MiB，明显缩小。

## 托盘待命

本机 32 逻辑处理器、30.6 秒样本：工作集峰值约 **18.7 MiB**，私有内存约 **2.1 MiB**，单核 CPU 平均约 **0.20%**，整机约 **0.006%**。配置端口未监听，按需设置进程已退出，托盘健康并注册到系统。工作集包含共享页面，私有内存为独占提交量。不同机器与负载会影响数字。

显示引擎另在 Zed 内部使用内存。此前对同一隔离进程启用后的空闲样本，工作集增量约 11 MiB、私有内存约 9.6 MiB；这不是滚动、输入或大项目帧耗时测试。保留字体、调用位置与编辑内容保护，不宣传零开销或全部界面覆盖。

## 实现和复测

日常托盘只使用 Rust 与系统 API，不加载设置服务。按进程名预筛选后核验完整路径，待命约 30 秒兜底扫描、有编辑器时约 10 秒，文件系统事件驱动更新。透明托盘图标预生成 RGBA，避免运行时图像解码和 Python。临时监控错误会低频重试，不永久退出或忙等。

设置服务为独立 Rust 组件，前端约 340 KiB 静态资源，复用 Vue/Element Plus。只监听本机，最后页面关闭后约 15 秒释放，显式关闭立即结束；翻译在缓存写入完成后退出。工具 tools/test_native_settings.py 使用本机模拟接口验证真实 SDK、缓存、密钥不落盘及进程退出。

原始本机结果在 reports/multilingual-performance.json（本机保留）。发布包使用公开文件白名单，不打包 zed-zh-data、凭据、调试截图和用户资料。源码构建缓存位于项目外 .build-cache，旧原型保留 D 盘回滚副本。
