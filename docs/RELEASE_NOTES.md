# Release notes

## 0.4.0

- Windows recognizes supported display structures automatically, independently of Zed versions and executable hashes; unknown structures retain original text.
- Settings offer all 14 languages with a persistent, independent language preference.
- English and 13 translated product READMEs provide clearer downloads and platform capabilities.
- Official updates, existing profiles and offline everyday translation remain available. Linux keeps its separate approved-binary ptrace backend and command-line interface.
