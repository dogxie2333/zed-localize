# 本机启动、补丁与 AI 设置

## 首次安装

把项目或显示补丁发行包解压到固定目录，安装 Python 3.12 以上；源码安装还需 Rust 工具链与对应 Windows 链接器。运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File runtime/setup.ps1 -ZedExe D:\Zed\Zed.exe -WithSettings
```

依赖安装失败时脚本不会替换快捷方式。`-WithSettings` 包含 AI 设置页面和维护依赖；不传时只装显示补丁运行层。无需修改官方文件，也不需要 API 密钥即可汉化已适配的版本。

## 日常启动

安装完成后，原桌面和开始菜单的“Zed”快捷方式会指向独立 Rust GUI 启动器。双击即可打开官方 Zed 并应用中文显示补丁，没有终端窗口。

开始菜单“Zed 汉化设置”打开本机 AI 配置页面；“Zed（原版英文）”暂停自动汉化后打开原版。切换英文前先保存工作并关闭原 Zed，避免原版单实例机制把请求转交给仍在运行的中文进程。

不要删除 `local` 或 `.venv` 后继续使用已替换的快捷方式。项目代码、依赖和本地安装文件位于官方安装目录之外，官方更新不会覆盖它们。

## 补丁怎么工作

官方 `Zed.exe`、更新助手和签名文件保持原样。Frida 官方绑定负责进程挂接；离线词典在 DirectWrite 排版入口替换已识别的 UI 文案。编辑器/终端调用路径被排除，文件名加入保护名单；不上传用户项目内容。

Rust GUI 启动器和轻量守护器负责启动入口、快捷方式修复、重新出现的官方进程。Frida Python 事件控制器只在 Zed 会话期间存在，使用父子进程事件处理编辑器自身的重启和更新助手。没有翻译服务器参与绘制，没有启动时 AI 请求。

## 重启与官方更新

关闭后从“Zed”快捷方式再开，会重新应用汉化。编辑器自身重启/更新助手新建的进程由控制器接管；官方更新重建的桌面、开始菜单或任务栏快捷方式由守护器修复。

当前已验证官方 Windows x64 1.23.2 的指定安装包。适配数据以文件哈希绑定调用位置。后台维护从本项目拉取**经过验证的适配数据**，不下载执行任意补丁代码，也不由 AI 批准新的二进制版本。

**不能保证尚未发布的任意新版立即中文。** 若内部布局改变且没有对应适配，正常启动英文版，设置页面会显示未适配状态。适配发布后，下次重启自动恢复中文；不会为了换补丁强制结束未保存的编辑会话。

守护器在登录时启动，低频检查进程并使用文件系统事件修复入口；它不自动打开编辑器。设置页面仅监听 `127.0.0.1:18743`，只在手动打开设置时运行。

## AI 接入页面

页面复用 **Gradio** 界面组件、**LiteLLM** 供应商接入与 **OpenAI SDK** 兼容模型查询，不自写 AI HTTP 协议。

1. 选择 DeepSeek、GLM 国内 BigModel、GLM 国际 Z.AI 或其他兼容服务。
2. 核对 API 地址，查询或手动输入账号可用的模型。
3. 填写密钥，点击“测试连接”。这会完成一次小型模型请求。
4. 保存模型/地址配置。密钥默认不保存；只有你勾选对应选项时才通过 keyring 写入 Windows 凭据管理器。
5. 点击“检查新增文案并翻译”执行离线维护。译文与占位符经社区校验后生成草稿，既有有效译文和语境缓存优先复用。

页面不会自动展示或保存聊天中提供的密钥。配置文件只包含非秘密选项；模型和密钥可以在页面中随时切换。GLM 的具体模型以你的账号和服务区域为准，不把 DeepSeek 密钥用于 GLM。

“允许更新维护批量翻译”是用户授权开关；未提供凭据时不会调用收费 API。接入能力与二进制兼容性互相独立，翻译成功不代表新版 UI 挂接已经验证。

开启后，在守护器收到安装目录或快捷方式变更事件时，最多每小时检查一次公开上游版本；仅在检测到变化或有未完成翻译时使用已保存凭据。不会下载模型，也不会在绘制路径上翻译。当前不会自动将待审新译文加入显示词典；需要社区校验、人工审查与适配发布。

## 回滚

先保存工作、退出 Zed，然后在项目目录运行：

```powershell
powershell -NoProfile -File runtime/install-startup.ps1 -Uninstall
```

该操作停止本项目入口守护器，恢复备份的原桌面/开始菜单/任务栏快捷方式，并移除本项目登录守护项。官方程序与用户 Zed 资料不删除。再次安装使用同一脚本不带 `-Uninstall`。

本机报告在 `local/runtime-status.json`，兼容检查在 `local/compat-last-check.json`；不包含密钥、编辑内容或模型错误正文。
