# 使用说明

## 初始化

1. 下载 `Zed-Localize.exe`，放入固定、可写的文件夹并运行。
2. 选择包含 `Zed.exe` 的安装文件夹与目标语言。
3. 选择开机自启或手动，保存后启动 Zed。

配置页只在第一次初始化和手动打开时运行；关闭后释放服务。无需配置 AI 即可使用已有词典。设置页语言、Zed 翻译语言与 AI 翻译语言分别保存。

## 启动方式

| 选择 | 日常使用 |
|---|---|
| 开机自启、接管快捷方式 | 登录后启动托盘，照常使用 Zed 快捷方式 |
| 手动、接管快捷方式 | 打开 Zed 快捷方式时自动启动工具 |
| 不接管快捷方式 | 手动运行本工具启动 Zed |

工具使用原有 Zed 用户资料，保留设置、登录、插件和项目。

## 托盘

右键可打开设置、启动 Zed、暂停翻译、隐藏图标或退出。隐藏图标后监控继续运行；可重新运行工具恢复图标。退出工具不会关闭 Zed。

## 更新

照常更新官方 Zed。Windows 启动时自动定位显示调用结构，不需登记新版本号或哈希。结构发生不兼容变化时保留原文，并提示未识别显示结构；更新本工具即可获取新的检测规则。

更新工具时替换 EXE，保留旁边的 `zed-zh-data/`。该目录保存设置、语言资源和缓存。

## AI 翻译

在设置页选择 DeepSeek、GLM 或 OpenAI 兼容接口，填写地址、模型和密钥。可以一次选择多种语言，批量处理新增文案。密钥可自行选择存入 Windows 凭据管理器。AI 只生成待审草稿，日常启动、输入和显示不会调用 AI。

## 卸载与还原

先在设置中关闭自启和快捷方式接管，再退出工具并删除 EXE。原快捷方式由备份恢复。重启 Zed 可回到原文。需要保留配置时，不删除 `zed-zh-data/`。
