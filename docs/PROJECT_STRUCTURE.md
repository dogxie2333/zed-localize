# 项目结构

| 目录 | 内容 |
|---|---|
| `src/` | Rust 启动器、托盘、结构检测、按需配置与 AI SDK |
| `web/` | Vue / Element Plus 设置页与 14 种语言 |
| `assets/locales/` | 社区显示词典 |
| `data/` | 语言清单与公开翻译语境 |
| `tools/` | 社区工具集成、维护与测试 |
| `runtime/` | 快捷方式、自启与恢复 |
| `packaging/` | Windows 与 Linux 分发构建 |
| `docs/` | 使用与开发说明 |
| `licenses/` | 上游许可声明 |

用户状态、凭据、构建缓存和本机报告不进入仓库或发布包。历史目录名保留用于兼容既有配置。
